# UI asset plan

## Current pass

The first UI cleanup uses small original inline SVGs for sound, stealth, run, Might, and level-up affordances. This keeps the VSIX lightweight, avoids unreviewed third-party provenance, and gives the sidebar a coherent icon language while the layout is being tuned.

## Candidate purchased packs

- Fantasy RPG GUI (pack 7): use selectively for panel frames, tabs, and a small number of primary action treatments. Do not import the full archive; the store page lists a very large package.
- Skill and Ability Icons (pack 1): use for level-up cards and Guild Might once the exact icon subset is selected.
- Resource/Commodity/Tool Icons (pack 3): use for gold, token, health, and progression badges.
- Technology and Skill Icons (pack 4): use for sound, stealth, settings, and telemetry state affordances if its style matches the GUI.
- Pixel RPG Monsters (pack 6): use for enemy/boss summary portraits and encounter markers.
- Pixel Hero Maker (pack 5): optional hero portraits after the six MVP classes have stable silhouettes.
- Food/Drink/Fruit (pack 2) and the broad utility set (pack 8): deferred; they are not needed for the current MVP surface.

Before packaging purchased art, retain the Unity invoice/license terms and a provenance manifest, import only the selected files, and add an asset-specific packaging test. The Unity pages identify the cited packs as Extension Assets under the Standard Unity Asset Store EULA; the project still needs the buyer's actual license record before embedding them.
