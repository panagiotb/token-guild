# DLC expansions: out-of-scope reference map

> Planning status (2026-08-01): retained reference only. DLC is explicitly outside the Token Guild MVP and this document does not authorize implementation.

## 1. Overview

This document details all 5 official *Vampire Survivors* DLC expansion packs mapped to **Token Guild** retro fantasy classes, weapon evolutions, and stage environments.

---

## 2. DLC Expansion Matrix (1:1 Reskin)
