# Relics and meta unlocks: planning map

> Planning status (2026-08-01): retained reference. Only minimal unlock/relic foundations exist; verify each gate and its production UI before promoting it to current functionality.

## 1. Overview & System Unlocks

In **Token Guild**, **Relics** are permanent key items acquired through specific dungeon achievements, boss victories, or secrets. Once collected, they permanently unlock new core systems, UI panels, run modifiers, and meta-features across the entire extension.
